# Generador del index.html

`gen.py` arma `../index.html` desde `index.tpl.html` y sus tablas de tramos, marcas y sonidos:

```
python _gen/gen.py index.html _gen/index.tpl.html
```

El `index.html` generado también se puede editar a mano (o en el editor de HyperFrames). Los demás `.py` son ayudas de revisión.
